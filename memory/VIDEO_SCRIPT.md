# My Hotel Box — Tanıtım Videosu Script
**Format:** Ekran kaydı + voice-over · **Süre:** 12-14 dakika · **Dil:** TR

Bu script, Loom / Tella / OBS gibi bir araçla ekran kaydı yapanın sahne-sahne takip edeceği rehberdir. Voice-over Türkçe, ekranda da Türkçe yorumlar görünür.

**Önerilen kayıt aracı:** Loom (kolay), Tella (profesyonel), Camtasia (post-edit), OBS (ücretsiz).

**Önerilen ses:** ElevenLabs Türkçe AI sesi veya kendi sesiniz. Arka fon müzik → düşük volume, lo-fi, telifsiz (Pixabay).

**Önerilen demo hesabı:** admin@hotelbox.com / HotelAdmin2026! · property = "default"

## EK: Çekim İpuçları

1. **Önce konuyu genel anlat, sonra detaya in** — sahne sahne hem geneli hem detayı açıklar.
2. **Mouse hareketleri yumuşak** — köşeden köşeye atlama yerine yavaş yerleştirme.
3. **Ses kayıt** — ekran kaydı + ses ayrı kanalda kayıt → post-edit'te senkronize et.
4. **Subtitle** — Türkçe + İngilizce alt yazı ekle (uluslararası satış için).
5. **Resolution** — 1920×1080 minimum. 4K daha iyi (YouTube canlı kalır).
6. **Bitiş kart** — 5 saniyelik CTA + abone ol butonu.
7. **Müzik** — Pixabay "ambient corporate" kategorisinden, telifsiz, %15-20 volume.
