### 10. 💬 Revinate (Reputation+CRM pazar lideri)

## 🚨 BÖLÜM 3 — KRİTİK EKSİK ALANLAR (Aksiyon Gerektiren)

### 🔴 P0 — Çok Kritik (her biri anlaşma kaybettiriyor)

#### 1. **TÜRSAB Extranet Entegrasyonu** ⭐⭐⭐⭐⭐
- **Neden Kritik:** Elektra'nın TR pazarında bizi geçtiği TEK SİLAH bu. 12,000+ TÜRSAB acentası Elektra extranet'e doğrudan loglanıp envanter/fiyat görebiliyor. Biz bunu yapamıyoruz.
- **TR pazarda etkisi:** Acenta-dominated TR pazarda (özellikle Antalya/Bodrum) anlaşma kaybının %35'i bu sebep.
- **Yapılacak:** TÜRSAB üyeleri için bir "agency portal" (`/agency`) — onların kendi acenta hesaplarıyla giriş yapıp komisyon yapısı, kontrat fiyat tarifeleri, min/max stay'i görebileceği. PIN/email auth + per-property contract rates.
- **Süre:** 1 sprint
- **Etki:** TR pazarda Elektra ile eşitleniriz.

#### 2. **Gerçek Booking.com / Expedia XML Push (Premier Connectivity)**
- **Neden:** SiteMinder'ın `60 saniye push` lansman ortağı yapısı. Bizde mimari hazır, sertifika eksik.
- **Aksiyon:** Booking.com Connectivity Partner sertifikası başvurusu (form + 8-12 hafta süreç) + XML push prototype.
- **Süre:** 2-3 sprint + sertifika 2-3 ay.
- **Etki:** Anlaşmaların %40-65'ini kapatır.

#### 3. **Lighthouse-tipi Gerçek Compset Rate Shopping**
- **Neden:** Bizde MOCK pool var; gerçek pazarda Lighthouse $59'dan başlıyor, 3B veri noktası işliyor.
- **Aksiyon:** OTA Insight partner API key alıp adapter implementasyonu (mimari hazır — `routes/compset.py` adapter pattern). Ya da Lighthouse'un public partner programı.
- **Süre:** 1 sprint (anahtar geldiğinde).
- **Etki:** Compset 8/10 → 10/10.

#### 4. **AI 24/7 Concierge — Web inquiry (Eviivo modeli)**
- **Neden:** Eviivo otel sitesine widget koyup misafir sorularını AI ile yanıtlatıyor. Bizde Voice Concierge scaffolded ama web chat widget yok.
- **Aksiyon:** `/api/web-concierge/*` endpoint + booking_widget içine drop-in chat widget. GPT-5.2 + property knowledge base (politikalar, amenities, FAQ).
- **Süre:** 1 sprint (Universal LLM key var).
- **Etki:** Eviivo benzeri "24/7 AI concierge" branding'i kazanırız.

---

### 🟡 P1 — Önemli (rekabet edebilmek için zorunlu)

#### 5. **Public Developer Portal + Revenue Share**
- **Neden:** Marketplace'imiz 124 entegrasyonla iyi ama Mews 1,100+ Cloudbeds 300+ var. Developer portal olmadan büyüyemeyiz.
- **Aksiyon:** `/developers` route — API keys, scopes, OAuth app registration, sandbox env, revenue share (%10) sözleşmesi.
- **Süre:** 3-4 sprint.

#### 6. **Mews Tarzı Agentic AI Loops**
- **Neden:** Mews 2026 trendi olarak "autonomous agents" lansmanladı — biz reactive automation yapıyoruz ama autonomous (agent-driven) değiliz.
- **Aksiyon:** Mevcut `automation_rules.py` + `ai_predictions.py` üzerine "Agent" katmanı (LLM-tabanlı planlama → eylem zinciri → onay).
- **Süre:** 2-3 sprint.

#### 7. **Duetto Open Pricing Mantığı**
- **Neden:** Bizim grid'imiz harika ama Duetto'nun "segment/channel/room-type bağımsız" mantığı kuralsız.
- **Aksiyon:** Mevcut yield engine'i extend — segment×channel×room-type matrix ile multi-dimensional override.
- **Süre:** 2 sprint.

#### 8. **Wholesaler/Net Rate Distribution (Hotel Trader analog)**
- **Neden:** Cloudbeds Hotel Trader 140+ wholesaler partner, kullanıcının ekstra OTA çabası gerektirmiyor.
- **Aksiyon:** HotelBeds / TBO / Travelgate gibi wholesaler API'leri için adapter pattern.
- **Süre:** 3-4 sprint (her biri ayrı kontrat).

#### 9. **Tripleseat ROX Hyper-Personalization Metadata**
- **Neden:** Event line items'a "Sommelier slot", "Curated playlist", "Interactive dining" gibi yapısal alan eklenmemiş — Tripleseat 2026'da bunlarla fark yarattı.
- **Aksiyon:** `meeting_sale_items` schema'sına `experience_type` (sommelier/playlist/show) + `personalization_meta` JSON.
- **Süre:** 1 sprint.

#### 10. **Social SEO for Event Listings**
- **Neden:** Tripleseat onaylı etkinlikler kendi listings sayfasından Google'a yansıyor — biz public event page üretmiyoruz.
- **Aksiyon:** `/events/{property_id}/{slug}` public route + structured data markup + OG image generation.
- **Süre:** 1 sprint.

#### 11. **React Native Mobile App v1**
- **Neden:** Cloudbeds/Eviivo/Mews hepsinin native app'i var. Hotel ekibinin %70'i mobilden çalışır.
- **Aksiyon:** Capacitor (hızlı) veya React Native (native) — Ops + HK + My Tasks modülleri öncelik.
- **Süre:** 6-8 sprint.

### 🟢 P2 — Diferansiyasyon (rekabetçi kalmak için)

- 1 sprint.

#### 14. **Vacation Rental Dedicated UI**

- 1 sprint (sadece UI grouping).

#### 15. **Revinate Voice Channel** (sesli arama analitiği)
- WhatsApp Voice'a benzer ama Telephone call → STT (Whisper) → transcript analytics → sentiment.
- 2 sprint + Twilio Voice anahtarı bekleyen.

#### 16. **Direct OTA Channels: Hotels.com, Mr & Mrs Smith, HotelBeds**
- Eviivo'nun ön plana çıkardığı niş kanallar.
- 3-4 sprint (her biri ayrı kontrat).

#### 17. **AI Review Agent** (Lighthouse 2026 yeniliği)
- Mevcut yorum yanıtlama draft'larını oto-publish edebilir hale getir + AI Reviewer Agent rolü.
- 1 sprint (LLM var).
