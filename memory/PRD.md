# My Hotel Box - PRD

## Complete Hotel Management Platform

### All Modules
- **Dashboard**: KPIs, Timeline, Occupancy gauge, Revenue chart, Housekeeping widget
- **Housekeeping**: Room Board, Task Management, Maintenance Requests
- **Night Audit**: 5-check wizard (Check-ins, Check-outs, Payments, POS, Housekeeping), Revenue/Occupancy report, Complete & Close Day
- **Guest Profiles**: Rich detail with history, spending, preferences, tags, notes, loyalty tiers
- **Bookings**: Rooms, Calendar view, Booking list with Pay Link
- **Campaigns**: Template Library (6), Audience Segments (8), scheduling, template variables
- **Admin Panel**: Roles & Permissions, Module Settings, Auto Purchase Orders
- **POS**: Premium terminal, cart, modifiers, split bill, kitchen, stock deduction
- **Payments**: Stripe, iyzico, PayTR, Guest Portal, Reminders
- **Other**: Review Hub, Messaging (WhatsApp/Telegram/SMS), Surveys, Accounting (18 tabs), Stock
