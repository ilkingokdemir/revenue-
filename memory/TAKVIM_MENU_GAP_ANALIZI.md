# Takvim Rezervasyon Menüsü — Rakip Kıyası (Cloudbeds / Mews / eviivo)
## Bizde OLANLAR (quick-actions popover + detay paneli)
Check In, Check Out, No-Show, Add Note, Duplicate, Lock (kilit), Details, Cancel,
Send Link (check-in linki), Davet Kiti (WhatsApp+kopyala), Folio, Upsell,
Ödeme kaydı (Cash/Card/Bank/Channel), Print, ödeme durumu rozeti.
## EKSİKLER (rakiplerde olup bizde olmayan)
1. Oda Değiştir / Taşı (Cloudbeds "Assign/Move room", Mews drag-move) — popoverdan oda+tarih değiştirme
2. Rezervasyonu Böl (Cloudbeds "Split reservation") — konaklamayı iki odaya bölme
3. Onay E-postasını Yeniden Gönder (Cloudbeds "Resend confirmation")
4. Misafire Mesaj kısayolu (Mews messaging) — MessagingHub var ama takvim menüsünde kısayolu yok
5. Ödeme Linki Gönder kısayolu (Mews payment request) — pay-by-link sistemde VAR, menü kısayolu eksik
6. Tarih Düzenle (uzat/kısalt) popoverdan (eviivo diary edit)
7. Kayıt Kartı Yazdır doğrudan popoverdan (Print detayda var, menüde yok)
Öncelik önerisi: P0: Oda Değiştir + Ödeme Linki kısayolu, P1: Onay yeniden gönder + Mesaj kısayolu, P2: Split + tarih düzenle.
